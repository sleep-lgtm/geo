## 三、Core 模块调用链

```
─── /api/geo/generate ──────────────────────────────────────────────
  输入: {type, product_name, params, faq_list, ...}
    │
    ├─ ner.py.extract()          从输入文本提取实体
    ├─ jsonld.py.render()        生成 JSON-LD <script> 标签
    └─ page_generator.py.build() Jinja2 渲染 → 纯静态 HTML 输出


─── /api/detect/url ────────────────────────────────────────────────
  输入: {url} 或 {html}
    │
    ├─ crawler.py.fetch()        获取 HTML（URL 模式）
    ├─ scorer.py.score(html)
    │     ├─ _score_structure()  BeautifulSoup: JSON-LD / 语义标签
    │     ├─ _score_entity()     ner.py: 实体密度 / 唯一标识
    │     ├─ _score_semantic()   embedder.py: 余弦相似度（进阶）
    │     │                      简化版: 标题-正文关键词覆盖率（MVP）
    │     └─ _score_freshness()  规则: 广告/重复/时间戳检测
    └─ 返回 ScoreResult(total, structure, entity, semantic, freshness,
                        issues[], suggestions[])


─── /api/vector/chunk ──────────────────────────────────────────────
  输入: {html 或 text, metadata}
    │
    ├─ splitter.py.split()       语义分片（200-500字，保持完整句子）
    ├─ embedder.py.embed_batch() 批量向量化（Redis 缓存 SHA256 key）
    └─ 导出 JSON / CSV（含 chunk_text, embedding, metadata）


─── /api/crawler/start ─────────────────────────────────────────────
  输入: {site_url, max_pages}
    │
    ├─ crawl_jobs 插入记录，返回 job_id
    └─ Celery task_crawl_site.delay(job_id, site_url)
           crawler.py.crawl_site()  异步限速爬取（1-2s 间隔，随机UA）
           → 每页执行 scorer.py.score()
           → 结果写入 detect_records
           → 更新 crawl_jobs.progress / status
```

## 四、数据库 Schema

```sql
-- 用户
CREATE TABLE users (
    id          SERIAL PRIMARY KEY,
    email       VARCHAR(255) UNIQUE NOT NULL,
    password    VARCHAR(255) NOT NULL,        -- bcrypt hash
    role        VARCHAR(50) DEFAULT 'user',
    created_at  TIMESTAMP DEFAULT NOW()
);

-- 实体库 (F5)
CREATE TABLE entities (
    id          SERIAL PRIMARY KEY,
    type        VARCHAR(50) NOT NULL,          -- Product/FAQ/Article/HowTo/Organization
    name        VARCHAR(255) NOT NULL,
    fields      JSONB NOT NULL,                -- 实体字段，按类型不同
    user_id     INTEGER REFERENCES users(id),
    created_at  TIMESTAMP DEFAULT NOW()
);

-- GEO 生成页面
CREATE TABLE geo_pages (
    id          SERIAL PRIMARY KEY,
    title       VARCHAR(500),
    url         VARCHAR(2048),
    html        TEXT NOT NULL,
    jsonld      JSONB,
    user_id     INTEGER REFERENCES users(id),
    created_at  TIMESTAMP DEFAULT NOW()
);

-- 检测记录
CREATE TABLE detect_records (
    id          SERIAL PRIMARY KEY,
    url         VARCHAR(2048),
    total       SMALLINT,
    structure   SMALLINT,
    entity      SMALLINT,
    semantic    SMALLINT,
    freshness   SMALLINT,
    issues      JSONB,
    suggestions JSONB,
    user_id     INTEGER REFERENCES users(id),
    created_at  TIMESTAMP DEFAULT NOW()
);

-- 向量分片 (pgvector)
CREATE TABLE page_chunks (
    id          SERIAL PRIMARY KEY,
    page_id     INTEGER REFERENCES geo_pages(id),
    content     TEXT NOT NULL,
    embedding   vector(1536),                  -- OpenAI/通义千问维度
    metadata    JSONB,
    chunk_index SMALLINT
);
CREATE INDEX ON page_chunks USING hnsw (embedding vector_cosine_ops);

-- 爬虫任务
CREATE TABLE crawl_jobs (
    id          SERIAL PRIMARY KEY,
    site_url    VARCHAR(2048) NOT NULL,
    status      VARCHAR(50) DEFAULT 'pending', -- pending/running/done/failed
    progress    SMALLINT DEFAULT 0,
    total_pages SMALLINT DEFAULT 0,
    result      JSONB,
    user_id     INTEGER REFERENCES users(id),
    created_at  TIMESTAMP DEFAULT NOW(),
    finished_at TIMESTAMP
);
```

## 六、Embedding 缓存策略

```python
# embedder.py 核心逻辑
import hashlib, json
from redis import Redis

redis = Redis(...)
TTL = 7 * 24 * 3600  # 7 天

def embed(text: str) -> list[float]:
    key = "embed:" + hashlib.sha256(text.encode()).hexdigest()
    cached = redis.get(key)
    if cached:
        return json.loads(cached)
    
    vector = call_embedding_api(text)  # 通义千问 / OpenAI
    redis.setex(key, TTL, json.dumps(vector))
    return vector
```

相同文本只调用一次 API，7 天内全部命中缓存，规避重复计费。

## 七、打分器模块设计

```python
# scorer.py 接口
@dataclass
class ScoreResult:
    total: int
    structure: int   # 满分 30
    entity: int      # 满分 30
    semantic: int    # 满分 25
    freshness: int   # 满分 15
    issues: list[str]
    suggestions: list[str]

class GEOScorer:
    def score(self, html: str) -> ScoreResult:
        s = self._score_structure(html)   # BeautifulSoup DOM 解析
        e = self._score_entity(html)      # ner.py 实体密度
        m = self._score_semantic(html)    # MVP: 关键词覆盖; 进阶: 余弦相似度
        f = self._score_freshness(html)   # 规则检测
        return ScoreResult(s+e+m+f, s, e, m, f, ...)
```

四个维度完全解耦，MVP 先用简化版语义分，进阶时只替换 `_score_semantic` 方法。

## 八、部署架构（Docker Compose）

```yaml
# docker-compose.yml 结构
services:
  nginx:        # 端口 80/443，反代 + 静态资源
  frontend:     # Vue3 build 产物（nginx serve）
  api:          # FastAPI，gunicorn -w 4 -k uvicorn.workers.UvicornWorker
  worker:       # Celery worker，消费 Redis 队列
  postgres:     # PostgreSQL 16 + pgvector，数据持久化卷
  redis:        # Redis 7，仅内网可达，设密码
```

```
外网请求
   │ 443
   ▼

      ──/*──────→ /usr/share/nginx/html (Vue3 静态)

api ──────────→ postgres:5432
api ──────────→ redis:6379
worker ───────→ redis:6379 (消费队列)
worker ───────→ postgres:5432 (写检测结果)
worker ───────→ 外网 Embedding API
```

## 十、关键风险与设计应对

| 风险 | 架构应对 |
|------|---------|
| Embedding 重复调用费用失控 | SHA-256 hash → Redis 缓存，TTL 7天，批量调用接口 |
| 展示页被 LLM 爬虫忽略 | Next.js `output:'export'` 纯静态，Jinja2 后端渲染，禁止纯 CSR |
| JSON-LD 与页面内容不一致 | `page_generator.py` 同一数据源渲染 JSON-LD 和可见内容，无独立维护 |
| 爬虫封 IP | robots.txt 解析，1-2s 随机间隔，随机 UA 池，Celery 限速 |
| 实体识别误判 | spaCy + jieba 双引擎，词性标注过滤，规则兜底 |
| 打分扩展困难 | Scorer 四维度独立方法，接口不变可按需替换实现 |
